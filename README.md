# Arcavy

The quiet home for everything you own and love. Books, vinyl, board games, and whatever comes next.

Arcavy is a household-first collection manager. Add items from a photo, a barcode, an AI assistant, or a calendar event, review them, and keep track of what you own and what you've lent out.

**Status:** early. Nothing is built yet; the repo currently holds experiments.

## Getting started

```sh
mise install   # installs the tool versions from mise.toml
```

`mise run dev:<name>` serves an experiment and `mise run ci` runs everything CI runs.

## Repository

- `experiments/`: throwaway experiments, one self-contained folder each.
- `AGENTS.md`: conventions for contributors and coding agents.

Work is tracked in [GitHub Issues](https://github.com/stefanmeschke/arcavy/issues).
